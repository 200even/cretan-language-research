# Lead: `*21F-TU` ~ `*21F-TU-NE`

**Status:** survives strict filter  
**Lead type:** probable formal/morphological relationship  
**Meaning/function:** unknown

## Core observation

At Haghia Triada, the same two-sign base occurs both bare and with final `NE`:

- `*21F-TU`
- `*21F-TU-NE`

Most importantly, **HT Scribe 9 writes both forms** on different tablets, so the alternation cannot be dismissed simply as two scribes choosing different spellings.

- Numerical context: associated with `1`

### HT 87

- Local sequence begins: `*21F-TU-NE • MA-KA-RI-TE • ...`

- Derived transaction role: sender/header-like

### HT 7b

- Site: Haghia Triada
- Object: tablet

- Local sequence: `*21F-TU-NE 1 / DA-RU-*329 2`
- Numerical context: followed by `1`

- Raw inscription: https://lineara.xyz/items/HT7b.html

## Why this survives

1. Both forms are securely segmented words.
2. Shared stem contains two signs.
3. Bare and extended forms are both written by Scribe 9.
4. Extended form is independently replicated by Scribe 11.
5. Both occur in administrative texts at the same site.
6. No speculative sign-value substitution is needed.

## What it does **not** establish

`-NE` cannot currently be translated as a dative, locative, genitive, plural, or any other specific category.

The extended form occurs both as a numbered personnel-style entry and in an apparent header/sender position. That argues against assigning a simple “recipient case” value from the current sample.

## Transcription warning

Some scholarship transcribes the first sign of this sequence as `QI`, producing `qi-tu-ne`. The computational corpus used here conservatively labels the sign `*21F` and separately inventories a `QI` sign. Until this sign-value issue is resolved from specialist paleography, this repository retains **`*21F-TU(-NE)`** and does not build phonological arguments on `qi-`.

## Current hypothesis

Minimal claim:

`*21F-TU-Ø` ~ `*21F-TU-NE`

The final `NE` is plausibly a morphological or derivational extension of the same lexical base.

## Falsifiers / next tests

This lead should be downgraded if:

- the two forms are shown to be different lexical items despite the shared sequence;
- a specialist paleographic analysis explains the forms as orthographic variants unrelated to grammar;
- further attestations show `NE` occurring arbitrarily with this stem without contextual conditioning.

Next useful search:

- find other secure multi-sign stems with `X` ~ `X-NE` across the same scribe;
- test whether `-NE` correlates with heading/designation functions across independent stems;
- check GORILA and specialist commentary for prior analyses of this exact alternation.
