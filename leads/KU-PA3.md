# Lead: the `KU-PA3-` family

**Status:** strong lexical/onomastic family  
**Lead type:** Minoan name formation / Linear A -> Linear B continuity  
**Ordinary inflectional value of `-NU`:** weak

## Secure Linear A forms

- `KU-PA3`
- `KU-PA3-NU`
- `KU-PA3-PA3`
- `KU-PA3-NA-TU`
- `KU-PA3-RI-JA`

These are not all products of a substring graph; each listed form is securely segmented in an inscription.

## External Linear B control

Davis & Valerio compare:

- Linear A `ku-pa3-nu` with Linear B `ka-pa3-no`
- Linear A `ku-pa3-na-tu` with Linear B `ka-pa3-na-to`

in Knossian personal-name material.

This is a strong reason to interpret at least part of the family as **onomastic** rather than as a transparent nominal declension.

Source record: https://cris.unibo.it/handle/11585/795936

## Current interpretation

The most conservative analysis is:

- `KU-PA3-` is a recurring lexical/onomastic base;
- `KU-PA3-NU` and `KU-PA3-NA-TU` have especially strong Linear B name parallels;
- `NU` may help spell a consonant-final name component rather than functioning as a standalone grammatical `/nu/` suffix;
- the larger family may preserve Minoan name-building morphology.

This family therefore remains highly valuable for **Minoan -> Mycenaean phonological and onomastic continuity**, even though it became weaker evidence for generic Linear A case morphology.

## What this lead does not establish

- `NU = dative/genitive/plural/etc.`
- all `KU-PA3-...` forms refer to the same person;
- all endings after `KU-PA3-` are inflectional rather than derivational/name-forming;
- the Linear B forms prove the Minoan language was Greek.

## Next tests

1. Inventory every `KU-PA3-...` form by tablet, scribe, numerical role, and co-occurring person determinatives.
2. Check whether the different forms ever occur in positions that would require different grammatical roles for the same referent.
3. Compare the whole family against Knossian Linear B anthroponyms, not only the two known parallels.
4. Learn which final Linear A vowels are likely orthographic when Minoan names are adapted into Linear B Greek.
