# Completed pilot: Mitanni Indo-Aryan positive-control test

**Status:** completed exploratory falsification test.

**Date:** 2026-08-16.

## Question

Does conventional Linear A transliteration contain an Indo-Aryan/Mitanni-like lexical cluster at a rate meaningfully above matched chance controls?

This was designed as a test of a proposed **contact/superstrate signal**, not as a claim that Linear A encodes Sanskrit or Indo-Aryan.

## Positive-control logic

The Late Bronze Age Mitanni sphere preserves a small but coherent Old Indo-Aryan linguistic package in cuneiform contexts: divine names, numerals, and equestrian terminology. That package is methodologically useful because it demonstrates what a genuine sparse superstrate looks like: several mutually reinforcing items in coherent semantic domains rather than isolated look-alikes.

The Linear A pilot used ten permissively CV-shaped targets inspired by that package, including forms corresponding approximately to:

- Mitra;
- Varuna;
- Indra;
- Nasatya;
- eka “one”;
- tri/tera “three”;
- panza/panca “five”;
- satta/sapta “seven”;
- nawa/nava “nine”;
- vartana “turn/round.”

The precise Linear A conventional readings were treated as approximate because they are projected from homomorphic Linear B signs.

## Matching rule

A primary hit had to be a **whole segmented Linear A sign group**, not a substring of a longer word.

Short two-sign matches were not accepted at face value. A matched control set was generated by reordering the same target syllables where possible, so that a hit had to outperform trivial syllable permutations rather than arbitrary nonsense strings.

## Result

Primary target set:

- Indo-Aryan-shaped targets: **3/10** whole-group hits.
- matched shuffled controls: **2/10** hits.

One-sided Fisher exact test:

- **p = 0.50**.

A deliberately more permissive treatment accepting `SA-TA` as a possible reduction of satta/sapta raises the target side to **4/10**, but still does not produce meaningful enrichment (approximately **p = 0.31** in the same simple comparison).

The apparent positive forms were short sequences such as `MI-TA`, `E-KA`, and `PA-ZA`. Trivial controls such as reversed `TA-MI` also occur in the corpus, illustrating the false-positive problem inherent in a large CV-syllabic corpus.

## Interpretation

**No detectable Mitanni-style Indo-Aryan cluster was found.**

The pilot does not prove that no Indo-Aryan loanword could ever occur in Linear A. It rejects the stronger claim that the present corpus shows an obvious Mitanni-like lexical package under permissive conventional readings.

The lack of a deity/numeral/equestrian cluster is especially important: a real sparse contact layer should generate mutually reinforcing items rather than three isolated short strings.

## Limitations

- This was not a fully blind machine-learning rediscovery of Indo-Aryan material from an unlabeled Mitanni/Hittite corpus.
- The positive-control anchors were known in advance.
- Conventional Linear A phonetic values are uncertain.
- The target set was small.
- The null model used matched permutations rather than a complete phonotactic generative model.

The result should therefore be described as a **pilot falsification**, not publication-grade statistical proof.

## Consequence for the project

External-language resemblance is now explicitly downstream of internal morphology.

Future claims of an Indo-Aryan, Anatolian, Hurrian, Semitic, Greek, or other lexical layer should first demonstrate that the detection method can recover a known sparse contact layer from a positive-control corpus while remaining quiet on negative controls.

## Status

**Rejected:** “Linear A contains an obvious Mitanni-style Indo-Aryan lexical/religious package.”

**Still open:** isolated Bronze Age contact loans, if independently supported by context and morphology.
