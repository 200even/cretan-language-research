## Promotion rule

A formal paradigm grid requires a second independent stem sharing at least two endings, with source-secure cells and the manual Tier A/B threshold registered in `experiments/multi-ending-grid-v01.md`. A single multi-ending stem is not promoted as a grammatical paradigm.
